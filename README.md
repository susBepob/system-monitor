# System Monitor

A small Windows app. It shows how busy your computer is.

## How to run it

1. Install Python.
2. Open a terminal in this folder.
3. Run `python system_monitor.py`.

If it asks for a missing package, install it with `pip install` and the package name.

## How to make an .exe

Run `pyinstaller system_monitor.spec`. The app shows up in the `dist` folder.
